# Custom Dataset Layout

This release targets single-camera videos that you record yourself (Custom).

## Scene folder

```
<scene>_training/                 ← name must end with '_training' (training loader convention)
├── images/                       input frames (00000.png ...)          [user-provided]
├── K.npy                         3x3 camera intrinsics                 [user-provided / auto-estimated]
├── first_bbox.txt                person bbox in the first frame        [preprocessing 1a]
├── masks/                        person masks (SAMURAI)                [preprocessing 2]
├── masked_images/, debug_masked.mp4   for checking masks               [preprocessing mv]
├── mmpose_result_mmpose/         whole-body keypoints (DWPose), crop bbox   [preprocessing 1b]
├── image_crop/, mask_crop/       person-centered crops                 [preprocessing 3]
├── crop_normals_sapiens2/        normal maps (.npy + .png for checking)     [preprocessing 4]
├── hmr_results/, global_smpl/, global_smoothed/,
│   global_all_opt/, global_after_shape_opt/, global_smpl_smoothed/   global pose optimization [preprocessing 5]
├── global_smpl_optimized/        final per-frame SMPL-X parameters     [preprocessing 6]
├── Head_img/, Head_mask/, Head_aabb.npy   face crops                   [preprocessing 7]
├── normals -> crop_normals_sapiens2                                    [preprocessing finalize]
└── joint_valid_frames.txt, joint_invalid_frames.txt                    [auto-generated by the training Pre stage]
```

Items actually read by the training loaders (`core/data/custom.py`, `core/data/scene.py`):
`images/` (original resolution only), `image_crop/`, `mask_crop/`, `K.npy`, `mmpose_result_mmpose/`, `global_smpl_optimized/`, `normals/`, `Head_*`, `joint_valid_frames.txt` (frame filter, if present).

## Two config files

| File | Role |
|---|---|
| `configs/legacy/SMPLX_dataloader/CUSTOM/<scene>.yaml` | Scene config — data path (`Path.training_folder`), body model settings. **Shared by preprocessing and training** |
| `configs/datasets/Custom-<scene>.yaml` | Training recipe — inherits the base recipe via `extends`, `scene_name`, `save_root_override` |

Templates: `CUSTOM/template.yaml`, `configs/datasets/Custom-template.yaml`.

## Included configs

- Templates: scene `CUSTOM/template.yaml`, training recipe `configs/datasets/Custom-template.yaml`
- Recommended recipe: `configs/datasets/Custom-05-v14_optim_v6_freeze100_scaleL2x100.yaml` (inherited by the template). `Custom-05-*` and `CUSTOM/05.yaml` are the scene configs used to develop this recipe; the data itself is not included.
- Alternative base recipes: `configs/default2.yaml` (v14_optim_v6), `configs/default2_loose.yaml` (v14_optim_v6, loose clothing) and `configs/default3.yaml` (v14_optim_v2).

## Recommended capture conditions

| Condition | Supported |
|---|---|
| Single person, full body | ✅ |
| Handheld / moving or rotating camera | ✅ (no camera tracking: preprocessing always assumes a fixed camera, and camera motion is absorbed by the per-frame SMPL-X optimization — DROID-SLAM is not used) |
| Zoom changes | ❌ (K is fixed) |
| Multiple people in view | ⚠️ tracks the most visible person in the first frame |
| 50–600 frames | ✅ recommended (more frames increase preprocessing and training time) |
| 1080p or higher | ✅ recommended (face and hand quality) |
